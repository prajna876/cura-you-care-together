About Cura

Finding the right doctor or nearby hospital can be difficult, especially when someone is in an unfamiliar location. Cura aims to make healthcare easier to navigate by bringing healthcare discovery and useful care-management features together in one place.


Our goal is to build a user-friendly healthcare experience that helps people explore nearby medical facilities, access doctor-related services, and organize their healthcare needs.


Live Demohttps:https://emergency-care-portal.lovable.app/

Try the deployed application:


https://emergency-care-portal.lovable.app/



The live demo shows the current version of the project. Features that require live hospital data, real doctor availability, persistent storage, or confirmed appointments depend on their actual integrations.



Features


Nearby Hospital Discovery — Explore nearby healthcare facilities using location-based tools where available.

Doctor Discovery — Browse doctor-related information and specialties through the interface.

Appointment Booking Interface — Access appointment-related workflows.

Emergency Care — Quickly reach emergency information and hospital discovery.

Health Records — A dedicated area for organizing health information.

Prescription Section — A dedicated interface for prescription information.

Medicine Reminders — Keep a list of medicines and track them in the interface.

Health Calendar — View dates and organize healthcare activities.

Kannada Assistance — Work toward making healthcare navigation more accessible to Kannada-speaking users.

Responsive UI — A layout designed for desktop and mobile screens.

Getting Started

Prerequisites


Node.js (a current LTS version is recommended)

npm

Git


Installation

1. Clone your repository


Replace YOUR_GITHUB_USERNAME with the GitHub account or organization that hosts the project.


git clone https://github.com/YOUR_GITHUB_USERNAME/cura-healthcare-portal.git

2. Move into the project folder


cd cura-healthcare-portal

3. Install dependencies


npm install

4. Start the development server


npm run dev

5. Open the local URL


Open the URL printed in your terminal, usually http://localhost:5173.



These instructions are for a typical React + Vite project. If you're working from Lovable, first export or connect the actual project source code to your repository and follow the scripts listed in its package.json.

Safety and Privacy

Cura is a healthcare technology project and is not a replacement for professional medical advice.



Do not rely on a prototype to verify hospital capacity or doctor availability.

Real appointment confirmations require a connected booking system.

Sensitive health information should only be collected or stored with appropriate security, privacy protections, and user consent.

For emergencies in India, call 112.
